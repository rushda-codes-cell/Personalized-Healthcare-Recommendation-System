# Day 05 – Exploratory Data Analysis

## Objective

To understand patient, disease, and medicine patterns using
exploratory data analysis.

## Work Completed

- Analyzed disease distribution.
- Analyzed medicine distribution.
- Studied relationships between diseases and medicines.
- Generated statistical summaries.
- Created visualizations.
- Identified important healthcare patterns.

EDA provided insights into the structure and relationships within the
healthcare data.
