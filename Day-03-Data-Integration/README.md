# Day 03 – Patient & Medicine Data Integration

## Objective

To integrate patient, disease, and medicine information into a
consistent data structure.

## Work Completed

- Loaded healthcare datasets.
- Identified common attributes.
- Matched patient and disease information.
- Connected disease information with medicines.
- Standardized column names.
- Integrated relevant datasets.
- Checked the resulting data structure.

## Outcome

Patient, disease, and medicine information were integrated into a
common dataset structure.
