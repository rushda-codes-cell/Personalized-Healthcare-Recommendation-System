# Day 09 – Patient Profile Representation

## Objective

To represent each patient using their demographic, clinical,
disease, and health-related characteristics.

## Work Completed

- Created patient feature vectors.
- Represented demographic information.
- Represented disease information.
- Represented clinical characteristics.
- Normalized numerical features where required.
- Created patient profiles.

## Outcome

A structured patient representation was developed for personalized
recommendation.
