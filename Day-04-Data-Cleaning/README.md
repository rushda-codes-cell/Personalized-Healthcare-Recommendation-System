# Day 04 – Data Quality Check & Cleaning

## Objective

To improve the quality and consistency of the integrated healthcare
dataset.

## Work Completed

- Checked missing values.
- Checked duplicate records.
- Identified inconsistent values.
- Corrected data types.
- Handled invalid records.
- Standardized categorical values.
- Validated the cleaned dataset.

## Outcome

A cleaner and more consistent healthcare dataset was prepared for
analysis.
