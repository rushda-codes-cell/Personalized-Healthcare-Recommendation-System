# Day 07 – Patient-Disease-Medicine Data Preparation

## Objective

To prepare the final relationship structure between patients,
diseases, and medicines.

## Work Completed

- Prepared patient records.
- Linked patients with diseases.
- Linked diseases with medicines.
- Created patient-disease relationships.
- Created disease-medicine relationships.
- Prepared recommendation-ready data.

## Outcome

The final patient-disease-medicine dataset was prepared for
recommendation modeling.
